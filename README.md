# 快乐密码

双色球、大乐透、福彩3D、快乐8、七乐彩、排列3、排列5、七星彩的选号与对奖安卓 App。

- 选号：机选、热号、冷号、形态、生日、星座、八字五行、开奖日五行、心意号
- 开奖：各彩种最新开奖、详情（销售额、奖池、各奖级注数和奖金、一等奖分布）
- 走势：经典格子走势图（带遗漏）和冷热图
- 对奖：拍彩票识别（手机上离线识别）或手动输入，支持复式、胆拖、组选
- 我的：实票和模拟票分开记账；开奖推送和中奖提醒

每期开奖独立随机，任何选号方式的中奖概率都和机选一样。理性购彩。

## 编译
推送到 main 分支后，GitHub Actions 自动编译，安装包在 Releases 里。签名证书和密码放在仓库的加密 Actions Secrets（KEYSTORE_BASE64、KEYSTORE_PASSWORD）里，不在代码里。

## 目录
- `www/` 页面和全部逻辑（`js/games.js` 彩种规则、`js/data.js` 开奖数据、`js/ocr.js` 票面解析）
- `runner/runner-src.js` 后台对奖脚本
- `android/` 安卓工程（`TicketOcrPlugin.java` 票面文字识别）
- `test/` 规则和票面解析测试
